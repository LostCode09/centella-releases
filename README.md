# Centella для macOS

VPN-клиент для macOS на sing-box и Xray: VLESS (Reality, XHTTP), Trojan, Hysteria 2, Shadowsocks, VMess, подписки.

Здесь только готовые сборки, исходного кода в этом репозитории нет.

## Установка

**Через Homebrew:**

```bash
brew install --cask lostcode09/tap/centella
```

**Вручную:** скачайте `Centella-<версия>.dmg` из [Releases](https://github.com/LostCode09/centella-releases/releases/latest) и перетащите Centella в «Программы».

### Первый запуск

Приложение не подписано сертификатом Apple Developer, поэтому macOS при первом запуске его заблокирует. Откройте «Системные настройки» → «Конфиденциальность и безопасность» и нажмите «Всё равно открыть» напротив Centella. Это нужно сделать один раз.

## Требования

- macOS 15 Sequoia или новее
- Mac с Apple Silicon (M1 и новее)

## Режимы

- **VPN**: весь трафик Mac, включая WebRTC, UDP и DNS, идёт через сервер. При первом подключении Centella попросит пароль администратора, чтобы установить системный помощник.
- **Системный прокси**: через сервер идут браузеры и программы, которые следуют настройкам macOS.
- **Только приложения**: локальный прокси с паролем для программ, в которых он указан вручную.

**Kill switch** (только в режиме VPN) блокирует интернет при обрыве соединения или постоянно, пока VPN не подключён.

## Удаление

```bash
brew uninstall --cask centella
```

Если ставили вручную: «Настройки» Centella (⌘,) → «Удалить помощник…», затем перенесите Centella.app в корзину.
